# Monad Marbles

A 3D physics-based marble racing game
powered by the Monad blockchain.

## Tech Stack
- Next.js / React
- Node.js
- Rapier Physics
- Socket.IO
- Solidity
- Railway Hosting

## Project Structure
- web/ - Frontend and 3D game
- race-server/ - Physics and race coordination
- contracts/ - Monad smart contracts
